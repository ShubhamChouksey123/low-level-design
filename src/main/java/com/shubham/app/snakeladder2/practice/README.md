# Snake and Ladder Game

## Functional Requirements
- Users should be able to register for a game
- User should be able to create a custom board with different snakes and ladder 
- User should be able to roll and dice and move to the new position. 
- A winner should be decided based on player reaching the end position first 


## Entities 

- Game
  - User 
  - Board 
    - Snake 
    - Ladder
  - GameCreationService
  - GameControllerService
