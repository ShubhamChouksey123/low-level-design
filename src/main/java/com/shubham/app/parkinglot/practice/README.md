
# Parking Lot System

## Functional Requirements
- Admin should be able to add layout of his parking lot with exact open spots 
- User should be able to get a ticket to the empty parking spot 
- User should be able to vacate that spot anytime. 
- No ticket to be issues in case all parking spot are occupied.

### Out of Scope
- Reservation of Spot


## Entities and their Relationship

- Spot 
- ParkingLot
- Ticket
